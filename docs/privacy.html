🔒 Политика конфиденциальности

Приложение: «Склад-Инвентори-Сканер»

Дата публикации: 10 сентября 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности описывает, как мобильное приложение «Склад-Инвентори-Сканер» обрабатывает и защищает информацию пользователей.

1.2. Используя Приложение, Пользователь принимает условия настоящей Политики.

2. Какие данные собирает Приложение

2.1. Приложение НЕ СОБИРАЕТ, НЕ ПЕРЕДАЁТ И НЕ ХРАНИТ какие-либо личные данные пользователей (имя, адрес, номер телефона, e-mail, геолокация, данные банковских карт и т.п.).

2.2. Приложение НЕ ТРЕБУЕТ РЕГИСТРАЦИИ и не создаёт учётные записи пользователей.

2.3. Все данные, вводимые пользователем в Приложение (названия товаров, количество, цены, категории), хранятся ИСКЛЮЧИТЕЛЬНО ЛОКАЛЬНО на устройстве пользователя и никуда не передаются.

3. Передача данных третьим лицам

3.1. Приложение НЕ ПЕРЕДАЁТ никакие данные третьим лицам, так как просто не имеет доступа к каким-либо данным пользователя.

3.2. Приложение использует рекламный сервис Яндекс.Реклама, который может использовать идентификатор устройства для показа рекламы. Яндекс.Реклама обрабатывает данные в соответствии с собственной Политикой конфиденциальности. Пользователь может отключить персонализированную рекламу в настройках своего устройства.

4. Безопасность

4.1. Приложение не имеет доступа к интернету для передачи данных (за исключением загрузки рекламного баннера).

4.2. Пользователь самостоятельно несёт ответственность за сохранность данных своего устройства и регулярное создание резервных копий через встроенные функции экспорта (Excel, PDF, CSV).

5. Изменение Политики

5.1. Правообладатель оставляет за собой право вносить изменения в настоящую Политику. Новая редакция вступает в силу с момента её публикации на данной странице.

5.2. Пользователь обязуется самостоятельно отслеживать изменения в Политике.
